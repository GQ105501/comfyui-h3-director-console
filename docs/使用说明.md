# comfyui-h3-director-console 使用说明

本文适用于 `comfyui-h3-director-console` 0.2.0。插件把多镜头素材管理、顺序执行、重抽、连续性和可选二次采样集中到 ComfyUI 侧栏；本文说明启用前检查、模型和节点依赖、实际操作及故障排查。

## 1. 环境要求

- Python 3.10+；Windows、Linux 的目录写法按各自 ComfyUI 安装位置调整。
- ComfyUI 0.33.4+，推荐 0.34.0+。
- NVIDIA GPU；4070 Ti 12GB 建议先用 `0.4 MP + 720P 二采`，质量优先可改为 `0.6 MP`。
- 安装或更新插件、节点、模型后必须重启 ComfyUI。

## 2. 模型依赖与放置位置

文件名必须与下表完全一致。`<模型根目录>` 是 ComfyUI 默认的 `ComfyUI\models`，或在 ComfyUI/Comfy Desktop 中配置的额外模型目录；同一个模型只需放在其中一个已启用的根目录。

| 用途 | 文件名 | 放置目录 | 必需条件 |
|---|---|---|---|
| Ref2VA 主模型 | `minimax_h3_ref2va_pruned_int8_convrot.safetensors` | `diffusion_models\` | 多参考模式 |
| FL2VA 主模型 | `minimax_h3_fl2va_pruned_int8_convrot.safetensors` | `diffusion_models\` | 文生/图生模式 |
| 文本编码器 | `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` | `text_encoders\` | 必需 |
| 视频 VAE | `minimax_h3_video_vae_fp16.safetensors` | `vae\` | 必需 |
| 音频 VAE | `minimax_h3_audio_vae_fp32.safetensors` | `vae\` | 必需 |
| FL2V Turbo v1.1 | `minimax_h3_fl2v_turbo_4step_v1.1_768p_comfyui_bf16.safetensors` | `loras\` | 文生/图生加速；多参考为实验用法 |
| Ref2V Turbo v0.1 | `minimax_h3_ref2v_turbo_4step_v0.1_comfyui_bf16.safetensors` | `loras\` | 多参考专用加速 |
| 3D latent 放大模型 | `minimax_h3_latent_upscaler_3d_fp32.pth` | `latent_upscale_models\` | 开启二采时 |

模型可分散在多个已配置的模型根目录中，但分类子目录和文件名必须保持一致。导演台会检测当前模式所需模型；缺少文件时会在进入队列前给出提示。

## 3. 外部节点依赖

各仓库应完整安装到 `ComfyUI\custom_nodes\<仓库目录>`：

| 节点包 | 仓库 | 导演台使用的节点 | 何时需要 |
|---|---|---|---|
| ComfyUI 核心 | [ComfyUI](https://github.com/comfyanonymous/ComfyUI) | H3、模型加载、采样、音视频合成等核心节点 | 必需 |
| JZL MiniMax H3 | [ComfyUI-JZL-MiniMax-H3](https://github.com/wjluoxiao/ComfyUI-JZL-MiniMax-H3) | `JZL_MiniMaxH3ImageToVideoDual`、`JZL_MiniMaxH3CondSync` | 必需 |
| KJNodes | [ComfyUI-KJNodes](https://github.com/kijai/ComfyUI-KJNodes) | `PathchSageAttentionKJ` | 必需 |
| VideoHelperSuite | [ComfyUI-VideoHelperSuite](https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite) | `VHS_LoadVideo` | 上传参考视频时 |
| H3 latent upscaler | [Comfyui_Minimax_h3_latent_Upscaler](https://github.com/LBH-123-AI/Comfyui_Minimax_h3_latent_Upscaler) | `MinimaxH3LatentUpscaler3D` | 开启二采时 |

导演台已经内置以下节点，无需另装 Motion Context：

```text
H3DirectorConsole
H3DirectorMotionCondition
H3DirectorGeneratedAVMaskedContext
H3DirectorExistingVideoMaskedContext
H3DirectorMaskedAVBridge
H3DirectorLatentTailFrame
H3DirectorSaveAVLatent
H3DirectorLoadAVLatent
H3DirectorTrimAV
```

`ComfyUI-H3-Motion-Context` 可以保留作其他工作流使用，但不是本导演台的依赖。

## 4. 基本使用

1. 启动 ComfyUI，在右侧边栏打开“MiniMax H3 导演台”。若侧栏未出现，可加载 `workflow_templates\H3-Director-Console-review.json` 检查节点注册。
2. 新建项目，选择宽高比、百万像素、秒数和生成模式。
3. 新建镜头卡片，填写提示词并按模式上传素材：
   - **文生视频**：只填提示词，不上传素材。
   - **图生视频**：提示词 + 必填首帧 + 可选尾帧，最多 2 张图。
   - **多参考生视频**：最多 9 图、3 视频、3 音频，总数不超过 12。
4. 拖动镜头排序，点击顺序执行。生成结果直接显示在卡片中；选中单个镜头可重新生成。
5. 确认上一段满意后再生成连续的下一段，否则后段会继承需要重抽的连续性状态。

多参考提示词可使用 `<Picture 1>`、`<Video 1>`、`<Audio 1>` 引用素材。连续模式的 S002 以后会自动用上一段末帧占用 `<Picture 1>`，用户图片从 `<Picture 2>` 起自动重映射；因此续段最多上传 11 个用户素材。

## 5. 连续性、加速与二采

- **连续长镜头**：继承上一段音视频 latent 和真实末帧，适合连续动作。续段提示词只描述接下来的动作，不要要求突然切换远近景、焦段、机位或运动方向。
- **独立分镜**：每段从零生成，可自由换机位和景别，后期用硬切或转场拼接。
- **关闭加速**：固定 20 步、`res_multistep`、`beta`，Sigma Shift 为 `12/3`。
- **开启加速**：推荐 4 步、`euler`、`simple`，Sigma Shift 为 `6/3`。LoRA 不与模式强绑定，但界面会阻止明确不兼容的组合。
- **二次采样**：选中 720P/1080P/1440P/2160P 后继承基础宽高比。H3 会按 32 对齐，例如 16:9 的 720P 实际输出为 1280×736。

12GB 显存建议先关闭二采验证动作和连续性，定稿后使用 `0.4 MP + 720P 二采`。`0.6 MP + 720P` 通常更清晰，但速度明显下降；1080P 及以上容易溢出到系统内存。二采不是无损放大，原始远景脸部信息不足时不会自动恢复真实细节，优先调整构图、人物占比和基础分辨率。

## 6. 数据与迁移

导演台数据默认位于：

```text
ComfyUI\user\director_console\projects\*.json
ComfyUI\input\director_console\<项目>\<镜头>\
ComfyUI\output\director_console\<项目>\
ComfyUI\output\director_console\context\<项目>\
```

Comfy Desktop 可能把 `input`/`output` 指向共享目录，请以当前实例配置显示的实际路径为准。迁移时应备份插件目录、项目 JSON、上传素材、需要继续生成的 `context` latent，以及全部模型和外部节点。仅查看成片时只需复制项目视频；继续重抽或续写时不能遗漏项目、素材和 context。

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| `当前模式缺少依赖 H3DirectorMotionCondition` | 插件没有完整更新或 ComfyUI 尚未重启。确认 `continuity_nodes.py`、`vendor\h3_motion` 存在，然后完全重启 ComfyUI。 |
| `ModuleNotFoundError: llama_cpp` | JZL 插件会加载 Llama 后端。应在 ComfyUI 自己的 Python 环境中安装与 Python/CUDA 匹配的 `llama-cpp-python`，不要装到系统 Python。 |
| Manager 报 `InvalidChannel` | Manager 配置使用了失效 channel。恢复默认 channel 并更新 Manager；这不影响已经本地安装的导演台。 |
| 模型不存在或下拉列表没有文件 | 检查准确文件名、分类目录及额外模型路径配置，放置完成后重启 ComfyUI。 |
| 二采极慢、磁盘 100% 或显存不足 | 降到 0.4MP/720P、缩短片段或关闭其他占显存程序。磁盘持续繁忙通常是显存溢出后使用系统内存和页面文件。 |
| `shape ... is invalid` | 连续镜头之间的宽高比、尺寸、帧网格或旧 latent 不一致。统一项目设置，清理该项目的旧 context 后从第一个镜头重新生成。 |
| 生成视频一卡一卡 | 避免提示词要求长时间静止、定格或不必要的慢动作；使用连续明确的动作和镜头速度描述，并确认输出为 24fps。 |
| 后续连续片段略短 | 连续模式会裁掉用于保护衔接的重复前缀。需要严格总时长时，在后期剪辑阶段补齐或使用独立分镜。 |


排查时先查看 ComfyUI 启动日志中的 `IMPORT FAILED`，再检查浏览器开发者工具和 `/object_info` 中是否存在上述节点。不要在任务运行中替换模型或删除 context 文件。
